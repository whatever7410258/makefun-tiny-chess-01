An entry for the [tiny-chess-01 bounty on make.fun](https://make.fun/bounty/tiny-chess-01): a complete chess engine in one Python file under 4 KB. 10x12 mailbox board, alpha-beta with PVS and a transposition table, quiescence over captures, killer and history move ordering, material plus piece-square evaluation with an endgame king table. The search runs to a fixed node budget, so every game replays move-for-move.
